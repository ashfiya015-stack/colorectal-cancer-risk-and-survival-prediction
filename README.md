# 🩺 Colorectal Cancer Risk & Survival — Exploratory Data Analysis

## 📌 Project Overview

This project presents an Exploratory Data Analysis (EDA) of a colorectal cancer patient dataset containing **89,945 patient records and 30 variables**.

The analysis explores demographic characteristics, lifestyle factors, clinical conditions, healthcare access, treatment-related variables, survival status, and cancer recurrence patterns.

The main objective is to identify meaningful patterns and relationships in the data and communicate them through clear statistical analysis and visualizations.

> **Note:** This project is focused on exploratory and descriptive analysis. The observed relationships represent associations in the dataset and should not be interpreted as medical advice or causal relationships.

---

## 🎯 Objectives

The key objectives of this project are:

- Understand the structure and characteristics of the dataset.
- Assess data quality, missing values, and duplicate records.
- Explore demographic characteristics of patients.
- Analyze lifestyle and potential risk-related factors.
- Examine survival patterns across different patient groups.
- Analyze the relationship between cancer stage, tumor aggressiveness, and survival.
- Explore healthcare access and treatment-related factors.
- Analyze cancer recurrence patterns.
- Identify correlations among numerical variables.
- Generate meaningful insights through data visualization.
